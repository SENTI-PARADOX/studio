# **App Name**: YourShare

## Core Features:

- Send Files: Initiate file sharing process by selecting multiple files from the device.
- Receive Files: Enable the device to receive files from other devices.
- File Picker: Browse and select multiple files (images, videos, documents) from a gallery-style interface.
- Transfer Progress: Visually track the progress of each file transfer with a progress bar and pause/resume functionality.
- P2P Connection: Establish a peer-to-peer connection with other devices using Wi-Fi Direct / Hotspot / LAN; use a QR code or PIN for easy pairing.
- File Transfer: Reliably transfer selected files between two connected devices.
- Transfer History: Maintain a list of recently sent and received files with quick actions (e.g., open, share).

## Style Guidelines:

- Primary color: Modern blue (#558BFF) for a clean, trustworthy feel, inspired by digital communication aesthetics.
- Background color: Light blue (#E6EEFF), providing a soft and unobtrusive backdrop.
- Accent color: Violet (#7953D2), used sparingly to draw attention to key interactive elements.
- Headline font: 'Poppins', a geometric sans-serif, for a precise, contemporary and fashionable feel.
- Body font: 'PT Sans', a humanist sans-serif that combines a modern look with warmth.
- Use custom, elegant, and minimalist icons to represent files, actions, and status.
- Design a mobile-first, intuitive, and minimal interface with large, touch-friendly buttons.
- Incorporate smooth animations to enhance user experience and provide visual feedback.
